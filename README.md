# Non-Diffracting-Beams
Julia code used to describe various beams (Gaussian, Bessel, Frozen Waves, etc) and optical forces predicted by the generalized Lorenz-Mie theory.

Each folder has the code and corresponding images for a certain class of beams. Below you can see some Frozen Waves.
